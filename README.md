# Jarvis

Organização pessoal de Pedro: PWA instalável no iPhone e no PC, com dados no Supabase protegidos por login com 2 fatores.

Área disponível: **Mestrado** (experimentos com passo a passo de bancada, materiais, protocolos versionados e tarefas).

- Segurança: veja [SECURITY.md](SECURITY.md).
- Instruções para o Claude: [CLAUDE.md](CLAUDE.md).

## Instalar no iPhone
Abra `https://tranchop.github.io/jarvis/` no Safari → Compartilhar → **Adicionar à Tela de Início**.

## Instalar no PC
Abra o mesmo endereço no Chrome ou Edge → ícone de instalar na barra de endereço.
